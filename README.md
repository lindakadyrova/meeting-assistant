# Meeting Task Extraction

This project automatically extracts tasks, responsible persons, and deadlines from meeting recordings. Audio is transcribed locally with Whisper. Three approaches are then compared: rule-based, LLM-based, and hybrid. Results are stored in SQLite. All data is processed locally, with no external connections.
